 Проект 1: Автоматизация генерации через n8n + ComfyUI

### Суть проекта
Я развернула **полностью рабочий автоматический пайплайн** генерации изображений с использованием референса персонажа.  
Система построена на связке **Docker + n8n + ComfyUI API**.

### Что сделано мной
- ✅ С нуля настроена инфраструктура на **Docker Desktop**
- ✅ Развернуты контейнеры **n8n** и **ComfyUI**
- ✅ Настроено сетевое взаимодействие между контейнерами
- ✅ Создан workflow в **n8n**, который принимает референс и отправляет задачу в ComfyUI
- ✅ Настроен ComfyUI для работы с референсными изображениями (персонаж)
- ✅ Проведено тестирование стабильности пайплайна
